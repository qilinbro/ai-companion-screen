伴屏 Windows 本机版

双击“伴屏.exe”启动。无需安装 Node.js、打开终端或每次编译。
请保留此应用目录内的运行文件；桌面/工作区快捷方式可以直接指向伴屏.exe。

这是当前电脑专用版本，仍使用你原来的黑色角色和原动作。
原角色保留在现有工作区：
{{WORKSPACE_ROOT}}\vendor\grok-study\replica
该路径只用于本机加载，原角色文件没有复制到应用中。移动或删除原工作区后，角色将无法加载。
已移除奶油色备用角色，加载失败只显示提示，不自动更换角色。
本机专用版本不用于公开分享；当前公开构建不随附角色，只保留可操作文字入口。

模型地址、模型和系统安全存储密钥继续使用当前电脑原有配置：
{{WORKSPACE_ROOT}}\outputs\local-study-profile
配置和密钥没有复制到应用目录。屏幕授权仍只在当前运行有效。

单击角色展开输入；按住身体拖动；Ctrl+Alt+Space 唤出。
在设置中配置兼容模型服务及画布显示器。画布支持全屏、退出按钮和 Esc。
关闭窗口收至托盘；需要完全结束时，从托盘选择退出。
