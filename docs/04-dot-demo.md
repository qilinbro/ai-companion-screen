# 伴屏模型对话 Demo

更新：2026-10-21（Asia/Shanghai）。v0.2 的显示器选择、全屏、连接检测和本轮验证以 [v0.2 实现与验收](06-v0.2-implementation.md)为准。下文保留基础交互和 2026-10-20 验证历史，由用户配置的模型决定是否调用屏幕工具。

本次需求如何收敛、已经完成什么及下一步接续，见[对话总结与项目交接](05-session-summary-2026-10-20.md)。本文记录当前 Demo 的具体行为和验证。

## 当前行为

点击宠物或使用 `Ctrl+Alt+Space` 展开小输入框；快捷键不可用时从托盘展开。发送需求后进入单张画布，原角色留在角落。等待时显示三点动画，实际回复流式出现；可以停止、复制与收起。工具名称、参数和过程卡片不作为常驻界面元素。

设置通过图标按需打开，不预填服务或模型。保存配置后保留原需求，由用户再次发送。普通需求直接交给模型；前端不做关键词任务分类，也不使用固定分析充当模型结果。

按住宠物身体可拖动窗口，移动超过短按阈值后不触发单击展开；单击和键盘唤出仍保留。展开输入时临时避让屏幕边缘，收起后保留原宠物锚点。拖动通过可信本地桥接，由主进程读取实际光标位置，不接受页面指定桌面坐标。

角色动作与实际事件匹配：等待响应使用原 `thinking` 思考点变形；获取画面及等待模型分析画面时使用 `searching` 左右观察；实际文字流到来时使用 `writing` 铅笔动作。回复正常结束才显示 `happy`，错误使用 `confused`，约2.4秒后恢复；取消立即恢复待机，不触发完成反馈。拖动期间临时使用 `dragging`，松开后恢复当前业务状态。重复文字片段不重新启动角色动作。减弱动画模式降低运动，原角色回复改用安静工作表情，避免持续书写特效。当前本机统一原黑色角色，公开构建只有文字入口；早期原创角色验证保留为历史。未接入录音或命令执行，不假装使用这些功能。

## 模型与授权

使用用户填写的 OpenAI-compatible Chat Completions 地址、模型名称和密钥。调用屏幕并回答图片问题要求所选服务同时支持流式响应、工具调用与图片输入；兼容程度、费用、额度及模型效果取决于该服务。

密钥仅在桌面输入控件中短暂输入，经最小桥接交主进程管理，不回显、不存入 React 状态、日志或源码。未选择本机保存时密钥仅驻留运行内存；选择保存时使用系统安全存储加密，不使用明文回退。服务地址与模型名称可保存在本应用配置中。更换服务不会沿用旧服务密钥。

屏幕授权只在本次运行有效，重启默认关闭。编辑服务地址或模型会取消旧勾选，用户可在新值下明确授权。授权说明表明需要时将画面发送到该服务；没有授权时，模型工具请求返回拒绝，不获取或发送屏幕图片。显式拒绝看屏幕的当前需求也受本地拒绝守卫约束。

## 屏幕工具与数据

`capture_screen` 是唯一的代码层工具：按模型实际返回的工具请求获取一张主屏 PNG，再交给同一模型服务继续回复。没有持续监控、OCR、本地 HTTP 工具服务或终端执行。截图本身不理解画面，分析来自所选视觉模型，不保证原因判断正确。

对话、截图与图片预览保存在当前内存，不默认存盘、不写入活动或 localStorage。模型请求发送当前需求和有限近期文字上下文，获准时再发送本次截图；后续历史只含文字，不自动重发旧截图。服务/模型变更后前后端开始新会话，退出不恢复会话。

主进程校验可信窗口及请求范围，限制工具参数、响应大小与调用轮数；支持停止、超时和迟到结果隔离。当前不能执行命令、修改文件、搜索网页、控制应用、录音或连接历史功能面板中的外部账户。浏览器预览不具有桌面桥接。

## 设计参考与素材

黑白暖灰、细边框、三点等待与流式光标由项目自行实现。参考 [assistant-ui Dot Matrix](https://www.assistant-ui.com/design/components/dot-matrix) 与 [Vercel AI Elements Shimmer](https://elements.ai-sdk.dev/components/shimmer) 的视觉模式，不引入整套组件库或复制其源码。已安装的 UI UX Pro Max 与 web-motion-design 用于聚焦查询及动效建议。

源码开发入口为工程内 `npm run desktop:dev`；本机直接启动入口现为最外层 `伴屏.lnk`。原黑色角色仅从本机现有目录加载，不提交、不复制进公开构建或便携包。用户最新要求统一原黑色角色，原奶油色备用角色已移除；本机素材缺失时显示“原角色未加载”，公开构建显示可点击的文字入口。旧多场景代码与[历史产品参考](02-product-references.md)保留，但不作为默认产品入口。
