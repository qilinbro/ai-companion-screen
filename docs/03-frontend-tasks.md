# 伴屏 AI Companion Screen：前端开发任务清单

版本：v0.1，基于产品方案 v0.2 的历史完整任务清单

原清单日期：2026-10-19；状态说明更新：2026-10-20（Asia/Shanghai）

范围：Windows 电脑客户端前端优先，后续复用到联想平板。

> 本文保留完整前端路线与逐项验收要求，不是当前代码缺失清单。2026-10-20 的最小交付已采用 `idle / input / canvas` 三种窗口模式，实现桌面宠物拖动、折叠输入、工作画布、可信 IPC、真实主屏截图及兼容 OpenAI API 模型桥接；模型链路经过受控测试，用户实际服务验收仍待完成。当前没有真实语音、OCR、Shell 修复或跨屏能力。范围收敛、Windows 证据与剩余条件见[本轮会话总结](05-session-summary-2026-10-20.md)。下列复选框保留为完整验收清单，不能由局部实现、动画或预览自动勾选。

历史产品依据：[电脑常伴 Agent 方案](01-desktop-companion.md)。参考边界：[早期 Muse / New Computer Dot 与后续 OpenAI Dots](02-product-references.md)。本文将完整方案拆成前端任务，不覆盖用户后来收敛的当前交付范围，也不增加常驻页面。

## 1. 前端交付目标

让用户在电脑上完成“安静待机 → 唤出输入 → 在一张画布看过程和结果 → 收起后继续工作”的完整交互。记忆、权限、设置、活动和历史任务通过临时浮层访问。

必须保留的约束：

- 原方案只区分待机角色和工作画布两个主要工作状态；当前实现另用 `input` 表示用户要求的折叠输入，形成 `idle / input / canvas` 三种窗口模式。动画、任务状态和浮层不另算常驻主页面。
- 不创建仪表盘、功能宫格、多列聊天、常驻任务侧栏或大批状态卡片。
- 角色表达轻、反馈克制、默认静音、不抢焦点。Muse 参考落在持续协作，Dot 参考落在记忆延续，不复刻品牌或素材。
- 显示实际动作和结果；没有模型/语音/工具时，入口隐藏、禁用并说明，或明确标为演示。
- 首阶段无网络、无模型密钥时也能验证基础交互；不能因此声称已完成常伴 Agent。

## 2. 优先级与任务记录方法

- **P0：电脑前端基础，FE-001～FE-011。** 先完成两状态界面、输入、状态、手动记忆界面、桌面桥接与首阶段验证。
- **P1：真实能力联调，FE-012～FE-016。** 连接真实模型、屏幕、记忆检索、Agent 与主动反馈，对应产品第二、三阶段。
- **P2：后续扩展，FE-017～FE-019。** 语音、梦游、联想平板，对应产品第四、五阶段；不阻塞首版电脑前端。

本清单在制定时将全部任务记为“未开始”；此后已有局部实现，但尚未按下列完整标准逐项重审，未勾选不等于相关代码完全不存在。当前完成证据见[会话总结](05-session-summary-2026-10-20.md)。后续记录使用“未开始 / 进行中 / 界面已验证、联调待办 / 已验收 / 阻塞”，只有完成某项全部验收才勾选“已验收”，不使用任务勾选代替验证记录。

每项实施记录：负责人、开始/更新时间、实际文件、关联提交、验证环境、界面验证结果、真实联调结果、缺陷与阻塞原因。后端接口未就绪时，记录“待联调”，不能写成端到端功能完成。

## 3. P0：电脑前端基础

### FE-001：确定两状态交互与界面基础

- [ ] 已验收
- **负责**：前端。**依赖**：已有产品方案，无运行时依赖。
- **工作**：梳理待机、展开、输入、运行、结果、收起的状态图；确定角色、画布、输入和临时浮层的层级。建立颜色、文字、间距、圆角、焦点与动效变量，避免各组件自行拼样式。
- **交付**：两状态交互草图、组件清单和基础样式约定；仅为设计与开发依据，不宣称已有客户端。
- **验收**：一眼能区分待机与工作；最常见操作不依赖设置入口；错误/禁用/焦点样式都有定义。未确定的角色造型、配色细节列为待定，不冒充用户已确认。

### FE-002：搭建前端骨架与运行时适配层

- [ ] 已验收
- **负责**：前端，桌面工程配合。**依赖**：FE-001。
- **工作**：按 React/TypeScript 方案划分桌面渲染入口、共享角色/画布、状态与桥接适配层；区分主界面模式、浮层、用户草稿、任务数据和能力可用性，不把它们塞进同一个状态枚举。
- **交付**：组件骨架、状态入口、能力探测与桥接接口草案。开发预览适配器与真实桌面适配器分开，不能静默降级成 Mock 成功。
- **验收**：未连接桌面服务时明确显示“界面预览，未连接电脑服务”；有桥接时才展示对应真实能力；真实接口失败不回落到预写答案；重复挂载/收起/展开不会重复订阅事件。
- **联调**：桥接握手、能力列表与取消订阅需真实 Electron 验证；浏览器预览只算前端预览。

### FE-003：待机角色与轻量动画

- [ ] 已验收
- **负责**：前端。**依赖**：FE-002。
- **工作**：用原创 SVG/CSS 制作呼吸、眨眼、轻微动作，以及等待/反馈的表达；角色能通过鼠标和键盘唤出输入，拖动与点击区分。无真实录音或播放时，不出现听取/说话的真实能力提示。
- **验收**：没有任务、未开启跟进/梦游的纯待机不发起模型请求；角色不自动弹出长段话；拖动后不会误发送或误打开画布；减弱动画时取消明显位移/循环变化，仍可理解状态。收起画布不等于停止已经授权的后台任务，显示模式与执行状态独立。
- **联调**：跨窗口拖动、透明区域命中与位置保存属于桌面配合项；只在组件中改变位置不能算原生窗口拖动完成。
- **本地占位与后续进展**：早期学习占位 spike 只验证透明小窗、渲染接入和可替换边界；后续已在 Windows 验证宠物原生拖动、点击区分及收起后的锚点保持，见[会话总结](05-session-summary-2026-10-20.md)。位置跨重启持久化、多显示器及全部缩放等要求仍须独立验收，不因此勾选本任务。第三方学习角色仅本机开发加载，不进正式构建和分发；便携版保留原创回退。

### FE-004：单张工作画布与基础结果块

- [ ] 已验收
- **负责**：前端。**依赖**：FE-002、FE-001。
- **工作**：实现画布外壳、任务标题、真实当前动作、连续内容区与底部输入；支持文字、受限 Markdown、代码、图片和必要操作按钮。设置/记忆等浮层关闭后恢复原内容和位置。
- **验收**：长文本纵向滚动，代码横向滚动，图片保持比例；用户查看前文时不被新内容强行拉到底部，提供“回到最新”入口；复制给出实际成功/失败反馈。
- **边界**：默认禁用可执行 HTML、脚本和未经验证的链接协议。代码块仅展示/复制，不提供任意运行按钮；不存在真实产物时不显示“已生成文件”或可用下载入口。

### FE-005：文字输入、草稿与发送行为

- [ ] 已验收
- **负责**：前端，运行时配合。**依赖**：FE-004、FE-002。
- **工作**：支持多行输入、Enter 发送、Shift+Enter 换行；处理中文输入法组合状态、空白输入、长度限制、重复点击和服务不可用。收起再展开保留本轮草稿，默认不持久保存全部输入。
- **验收**：中文候选确认不会误发送；请求发出但未收到接收确认时显示“正在发送”，不提前生成成功状态；同一请求重试复用请求 ID 并由运行时去重。
- **运行中输入**：提供明确的“补充当前任务 / 作为下一项”等选择；运行时不支持时保存草稿并说明，不能把一段补充自动解释为新授权。
- **无模型状态**：只在真实电脑回执后显示“电脑已收到，未调用 AI”；仅在预览环境时显示“本地预览内容”，不混用文案。

### FE-006：任务状态、真实进度与停止

- [ ] 已验收
- **负责**：前端，运行时配合。**依赖**：FE-002、FE-004、FE-005。
- **工作**：呈现 `waiting / running / completed / failed / cancelled`，等待说明原因；使用实际动作、真实步骤，不用计时器编造百分比。将发送中、连接异常与任务状态分开。
- **首阶段联调**：由运行时真实接收并执行可停止的本地检查任务，显著标为“本地连通性测试”，验证接收、执行、停止与终态；不等到模型接入后才验证取消，也不用前端计时器模拟工具执行。缺少该运行时接口时仅记“界面已验证、联调待办”。
- **验收**：点击停止先显示“正在停止”，收到运行时确认才显示取消；取消失败、停止超时或任务已完成时如实显示；迟到文本、旧轮次或重复事件不覆盖终态。
- **结果依据**：没有实际任务结果不显示“已完成”；部分结果、流中断、工具截断须保留可用内容并明确未完成范围。
- **重连**：连接失去时显示“状态待确认”，重新读取快照，不凭前端缓存判断已取消或自动重跑任务。

### FE-007：桌面窗口、托盘与快捷键的前端接入

- [ ] 已验收
- **负责**：前端与桌面工程。**依赖**：FE-002、FE-003、FE-004。
- **工作**：接入唤出、收起、置顶开关、窗口关闭、托盘恢复和退出；首次说明“关闭到托盘，任务可能继续”，提供直接退出入口。
- **验收**：Esc 优先关闭最上层浮层，再收起画布；有未保存编辑时先处理草稿；按 Esc 不默认取消任务。托盘恢复同一画布，不创建重复窗口或任务。
- **真实桌面验收**：快捷键占用时可改；100%/125%/150%/200% 缩放和多显示器切换不丢窗口；移除显示器后角色回到可见工作区。
- **职责**：快捷键注册、原生窗口边界、托盘与进程退出由主进程实现，前端只通过最小桥接调用并展示真实回执，不把隐藏元素当应用退出。

### FE-008：长期记忆管理浮层

- [ ] 已验收
- **负责**：前端，存储接口配合。**依赖**：FE-002、FE-004、FE-009。
- **工作**：展示类别、项目范围、来源、更新时间，支持手动新增、编辑、删除、导出、空列表和搜索/筛选；所有操作在临时层完成，不变为常驻记忆侧栏。
- **验收**：保存和删除需等待真实存储回执；失败保留输入并可重试；未保存内容关闭时有明确处理；删除后立即更新可见列表，但不能在接口失败时假装已删。
- **真实联调**：新增后退出重启仍存在，修改后重启显示新值，删除后不再读取；导出取消与失败不显示成功。桥接未接入时只可验证交互，并明确“未保存”。
- **边界**：本任务仅是手动记忆管理；模型是否检索、引用或忘记由 FE-014 另行验收。

### FE-009：临时浮层、基础设置与能力状态

- [ ] 已验收
- **负责**：前端，桌面/权限接口配合。**依赖**：FE-002、FE-001。
- **工作**：建立统一可关闭浮层，承载设置、权限、活动、历史任务选择和后续设备配对；首阶段只开放已经接通的基础设置与实际活动，不填充虚构任务记录。
- **验收**：同一时间只有一个主要浮层；打开时焦点进入，关闭后回到触发点；修改中断有清晰处理；接口未接入时说明能力不可用，不提供会悄悄丢弃设置的开关。
- **凭据边界**：密钥只在受信任设置界面短暂录入，经窄 IPC 交主进程；不得进入普通对话、前端持久存储、构建产物或日志。公开配置只返回是否已配置，不返回密钥。当前主进程可按用户选择保留于本次运行或用系统安全存储加密保存，失败须明确提示；实际服务与完整凭据流程仍独立验收。
- **错误状态**：缺配置、服务断开、版本不匹配、权限撤销分别给出简短原因与可执行下一步，不能都写成“出错了”。

### FE-010：可访问性、视觉一致性与窗口适配

- [ ] 已验收
- **负责**：前端。**依赖**：FE-003～FE-009。
- **工作**：补齐键盘路径、可见焦点、按钮名称、对比度、减弱动画、文本缩放和窄窗口布局；状态不能只用颜色或角色表情表达。
- **验收**：不用鼠标可完成输入、停止、复制、记忆编辑和关闭浮层；屏幕阅读顺序合理；流式内容不逐字高频播报，只播报必要状态与完整片段。
- **尺寸检查**：在角色小窗、标准画布、窄屏工作区和不同 Windows 缩放下验证；长文件名、长代码、中文与英文混排不遮挡主操作。小窗口允许内容滚动，不通过缩小所有文字勉强塞入。
- **运行表现**：收起后暂停无必要的界面动画；反复展开/收起与长输出后没有重复订阅、失控的循环或持续资源增长。记录实际环境与测量，不预写帧率或功耗成绩。
- **后续约束**：触屏目标、软键盘、横竖屏属于 FE-019 实机工作，不用桌面缩放结果替代平板验收。

### FE-011：首阶段前端验证与交付记录

- [ ] 已验收
- **负责**：前端与桌面工程。**依赖**：FE-001～FE-010。
- **工作**：串联“启动 → 待机 → 输入 → 真实 IPC 回执 → 收起/恢复 → 手动记忆增删改查 → 退出/重启”；记录安装、启动、构建、验证和缺项。
- **验收**：无模型和网络时基础交互可用；真实回执与本次请求 ID 对应；无模型时绝不返回预写 AI 答案；托盘关闭与退出行为准确；打包后的 Windows 程序也完成一次操作验证。
- **生命周期验证**：使用明确标记的真实“本地连通性测试”任务，核对停止回执、终态和取消后的迟到事件处理，不用界面定时器代替运行时。
- **检查重点**：输入法误发送、重复订阅、停止/完成竞态、迟到事件、存储失败与多显示器恢复；不为每个样式变量编写重复实现的测试。
- **交付**：实际运行记录、界面截图/必要短录屏、缺陷与未联调项。浏览器样例只能标“前端预览”；没有真桌面运行记录就不勾选本任务。

## 4. P1：真实能力联调

### FE-012：真实模型文本流与会话连续性

- [ ] 已验收
- **负责**：前端，模型/任务运行时配合。**依赖**：FE-005、FE-006、FE-011；真实模型适配器。
- **工作**：接入接收确认、真实增量、最终结果、超时、上游中断和取消。第一段内容到来前仅显示真实等待动作；重试不能重复拼接旧输出。
- **发送范围**：用户可见所选模型提供者和将发送的文字/记忆/图像类型；在已有会话授权范围内复用许可，超出范围重新确认。拒绝外发时不调用云模型，基础本地操作仍可用。
- **验收**：使用真实模型请求，有可关联的请求 ID（提供者支持时）；上游断开保留并标记不完整结果；取消后的输出不进入下一轮；不硬编码回答、不以逐字计时假装流式生成。
- **连续性**：收起再展开仍是同一任务；新会话、当前上下文清理与历史任务恢复互相区分，不默认永久保存整段聊天。

### FE-013：授权屏幕上下文与当前画面结果

- [ ] 已验收
- **负责**：前端，捕获/权限/模型接口配合。**依赖**：FE-006、FE-007、FE-009、FE-012。
- **工作**：通过可信桌面流程选择窗口/屏幕；显示实际来源、捕获时间、暂停/停止与权限状态。画布可展开查看本次实际截图/裁剪范围，不默认长期保存图像。
- **两类授权**：屏幕捕获与向所选模型提供者发送本次图像/相关上下文分开说明和控制；仅选择窗口不等于允许外发。拒绝外发时可保留获准的本地预览，但不得调用云模型。
- **验收**：画面未授权、模糊、失效、窗口关闭或来源变化时明确说明；只有收到真实暂停/停止确认后才更新最终状态，等待期间显示正在处理。
- **真实验证**：电脑窗口当场修改英文与随机标记，重新请求后译文对应新画面；实际错误输出给出可见事实、可能原因与缺失日志。旧帧不能冒充当前画面。
- **边界**：框选是已授权来源上的裁剪，不宣称系统级独占区域权限；屏幕理解权限不产生电脑操作权限。这只算桌面实屏联调，跨屏另由 FE-019 验收。
- **清理**：停止/撤销后清除前端截图引用、对象 URL、待发送预览和失效裁剪范围；旧结果如保留须标历史内容，不能继续显示为“当前画面”。

### FE-014：确认记忆、引用来源与忘记后的反馈

- [ ] 已验收
- **负责**：前端，记忆/检索/模型接口配合。**依赖**：FE-008、FE-012；真实记忆检索接口。

## 7. 前端与桌面/运行时的接口清单

以下是完整路线的扩展联调需求草案，不表示当前完全没有 API。当前最小桌面桥接已在 `apps/desktop/src/demo/desktop.d.ts`、preload 与主进程实现，具体范围见[会话总结](05-session-summary-2026-10-20.md)；更完整的快照、授权、记忆、设备协议仍按后续实际实现固定，不把未实现的草案视为现有接口。

- **能力与版本**：当前桥接版本、模型/截图/记忆/工具/语音/梦游是否可用及不可用原因；能力列表不包含密钥。
- **任务命令与快照**：提交请求、补充/等待策略、取消、查询当前状态；含 requestId、taskId、runId、事件序号、等待原因、实际步骤与结果依据。
- **屏幕**：请求可信选择器、来源/权限快照、取帧时间与 captureId、暂停/停止确认；前端不能自行构造 sourceId 授权。
- **记忆**：列表、待确认、新增、修改、删除、导出、检索使用来源；写入/删除完成与错误必须有回执。
- **授权**：待授权对象、动作、范围、期限、外发接收方及用户决定；运行时执行前再次验证，界面确认不是绕过权限的凭据。
- **桌面生命周期**：唤出/收起/关闭/退出、置顶、快捷键与位置、系统睡眠/锁屏/恢复、通知点击。
- **后续媒体与设备**：真实录音/识别/播放/中断事件、梦游设置回执、设备连接与任务版本。

事件归并要求：忽略旧 runId 或过期序号、去重、取消/完成竞态采用运行时最终状态；重新连接先取快照。开发预览用例与真实事件同结构，但必须显著标记且不能落入真实验收记录。

## 8. 前端任务的统一完成标准

- 交互符合两个主状态，没有新增常驻列表或仪表盘；预览环境与未接能力明确标记。
- 正常、空、等待、不可用、拒绝、失败、取消及长内容场景均能操作；失败不会丢失用户输入或伪造成功。
- 键盘、中文输入法、缩放、焦点和减弱动画完成验证；只在预览环境通过要明确记录。
- 依赖真实能力的验收有实际接口/设备/数据依据，不能用动画、固定响应或前端计时替代。
- 相关启动/构建/检查命令必须实际执行，记录版本、结果与未完成项。早期角色窗口 spike 的检查不能替代后续验收；2026-10-20 已有新增构建、Windows 交互与受控模型链路证据，见[会话总结](05-session-summary-2026-10-20.md)，仍不代表本文所有完整任务已验收。
- 每次交付说明“实现了什么、如何启动、如何验证、仍缺什么”。前端可独立验收的部分先交付，后续能力缺失不阻止独立工作，也不升级成功声明。
