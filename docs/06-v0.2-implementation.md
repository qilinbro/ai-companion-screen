## 已完成的实现

- 设置按需展开，可选择画布显示器，标明主屏、副屏及缩放比例。画布进入指定显示器后可全屏，支持退出按钮和 Esc。退出恢复窗口尺寸；收起回到单独保存的宠物位置。
- 同一窗口承载同一会话，搬动和全屏不重新挂载会话，不重新发送模型请求。窗口位置以 Electron 的 DIP 坐标计算，依可用工作区约束位置，响应显示器增删、缩放和工作区变化。
- 画布位置与采集来源独立。屏幕工具始终按当前运行授权读取 Windows 当前主屏；移动画布不会改读副屏。拔出画布所在屏幕后回退到仍存在的屏幕；重新连接会更新设置中的列表。
- 模型设置保留服务地址、模型和密钥。连接检测分别检查文字响应及合法工具调用格式，不执行截图、不写入会话、不宣称已经验证视觉理解。认证、地址、模型、能力、网络、超时及响应格式错误有相应说明。
- 需求先交给配置的模型。只有合法的 `capture_screen` 请求通过本地权限检查后，才取得实际主屏图像并发回同一模型。后续历史只保留有限文字，需要新画面时重新采集。
- 画布优化标题、段落、列表、引用、代码块和复制；流式更新时尊重用户向上阅读的位置，提供返回底部入口。全屏限制正文宽度，放大阅读字号。
- 本机统一加载原黑色角色，动作保持实际阶段语义；停止立即待机，拖动后恢复当前阶段，增量文字不重启动作。公开构建保留文字入口，不附带备用角色。
- 停止、关闭、睡眠事件、模型配置变更和退出均终止相关工作；取消后迟到事件不能更新已结束任务。恢复不自动重发任务。
- 通信、密钥和工具留在主进程；保留隔离、沙箱、受限 IPC 和发送方检查。旧直接截图入口也受当前运行授权约束。授权不持久化，服务或模型变化后重新授权。截图和会话默认仅驻留内存，密钥可选系统安全存储，无明文回退。

Windows 透明宠物窗口采用同一无边框窗口覆盖所选显示器完整范围的全屏策略。Electron 44.9.1 的透明窗口分支只改变窗口范围，`isFullScreen()` 不会反映此状态；依据[该版本官方窗口实现](https://github.com/electron/electron/blob/v44.9.1/shell/browser/native_window_views.cc)，本项目独立维护全屏状态，验收实际窗口范围、显示器覆盖及退出恢复，不以这个标志代替实际桌面检查。

## 简短演示步骤

1. 解压便携包，保留整个目录，运行 `伴屏 Demo.exe`。单击宠物或按 `Ctrl+Alt+Space` 展开输入，按住身体可拖动。
2. 打开设置，在“画布位置”选择显示器。进入画布后点击全屏，再用退出按钮或 Esc 返回；收起检查宠物是否回到原位。
3. 填写兼容服务地址、模型和密钥，点击连接检测。工具格式检测通过后仍需使用真实视觉模型验收图片理解。
4. 先发送普通文字需求；在设置中明确授权当前运行的主屏读取后，再询问当前页面。改变主屏内容后重新询问，检查模型是否取得新图。
5. 在流式回复期间停止，确认迟到文字不再出现。生成长回复后向上阅读、复制代码，再切换画布位置，确认回复和会话保留。
