## 2. 产品约束：只有待机和一张工作画布

电脑提供用户授权的屏幕上下文与工具执行能力；平板提供角色、输入、语音和结果呈现。借鉴 Dot、Muse 式陪伴的目标仅指持续记忆、角色表达与主动协作，不引入其未经确认的能力或素材。

### 待机

- 全屏留白与一个原创角色，具有呼吸、眨眼和轻微姿态变化；默认安静。
- 点击角色或轻触底部唤出文字输入，设置与连接入口弱化并按需出现。
- 未连接、连接断开时，用一句轻提示说明，必要时展开临时配对层。
- 不出现常驻仪表盘、功能宫格、多列聊天、侧边任务列表或成排状态卡片。

### 工作画布

- 用户提交问题后，在原位置展开一张纵向工作画布；角色缩小到边缘，保持画布主体清晰。
- 同一画布容纳译文、解释、代码、图片、当前动作和必要操作。长内容在画布内部滚动。
- 优先显示“正在获取授权画面”“正在分析”“正在检查结果”等真实动作；只有可计数的真实步骤才显示“2/4 步”。
- 完成后保留结果，由用户选择“继续”或“回到待机”；阅读中不自动清空。
- 设置、长期记忆管理与配对通过临时浮层打开，关闭后回到原状态，不形成第三个常驻主界面。

交互状态示意（设计目标，不是现有界面）：

```text
待机角色 → 唤出输入 → 单张工作画布 → 继续同一任务 / 回到待机
                         ↓
                 等待 / 运行 / 完成 / 失败 / 取消
```

角色的听取、思考、说话、庆祝等表现是动画状态，不能作为麦克风、模型或任务成功的证据。未接入语音时默认不提供可用麦克风按钮；若保留动画体验入口，必须写明“语音演示（未接入识别）”。

## 3. 架构与选型

第一版采用单仓库、npm workspaces、TypeScript。电脑运行一个本地服务，同一套 Web 界面提供 `/desktop` 和 `/tablet` 两个入口。先验证浏览器交互与局域网链路，后续再按设备实测选择 Android 包装或原生能力。

### 模块边界

1. **电脑控制页**：只在电脑本机打开；负责选择共享对象、画面预览、暂停、停止与授权范围管理。屏幕捕获必须由用户在电脑上点击触发。
2. **平板界面**：角色、单画布、文字输入、后续语音与临时设置。不持有模型密钥，不直接执行电脑工具。
3. **设备通信**：电脑服务负责配对、认证、设备角色、心跳、断线重连、事件排序与结果投递。
4. **模型适配器**：电脑服务接收授权画面与问题，调用已配置且支持图像输入的真实模型；文本流式结果转发平板。提供者、接口格式与模型能力需单独实测。
5. **任务与工具执行**：独立于屏幕理解，执行服务器验证过的工具调用并检查结果。首个工具不开放任意命令执行。
6. **记忆存储**：区分瞬时屏幕、短期会话、可管理长期记忆；电脑端持久化，平板只读取授权内容。

```text
电脑浏览器 /desktop
  用户授权的屏幕流 → 按需取一帧 / 用户框选后裁剪
                          ↓ localhost
                  电脑 Node.js 服务
                  ├─ 配对与通信
平板 /tablet ←局域网→ ├─ 任务状态与事件
角色 / 输入 / 单画布   ├─ 模型适配器 → 用户配置的模型服务
                  ├─ 工具执行器 → 用户选定的目录 / 应用
                  └─ 记忆存储
```

### 选择理由与依赖控制

- **Node.js 24 系列 + TypeScript**：与本机环境一致，前后端共用协议类型；模型请求优先使用内置 `fetch`。锁定依赖版本并提交 lockfile，不把本机补丁版本视为长期安全承诺。
- **React + Vite + 原生 CSS/SVG**：适合两状态交互与平板响应式布局；原创几何角色先用 SVG/CSS 动画，不引入 Live2D、3D 引擎或第三方角色包。Vite 的 Node 版本要求以[官方入门文档](https://vite.dev/guide/)为准，实施时检查所选版本。
- **Node 原生 HTTP/HTTPS + `ws`**：一个服务提供构建后的页面、配对接口和双向事件，减少跨域与多进程问题。Vite 开发入口只用于本机调试，不直接当作局域网配对服务暴露。
- **`zod`**：在服务端验证通信消息与工具参数；TypeScript 类型不能代替运行时验证。
- **存储渐进引入**：第一阶段仅持久化非敏感设置；配对会话与测试任务在内存。第五阶段再引入 SQLite 存储长期记忆并验证迁移、删除；不提前引入向量库、Redis、云账户系统或 Agent 框架。
- **浏览器按需截图**：先不用原生截图驱动、Electron 或桌面自动化包。屏幕理解不依赖鼠标键盘控制；后续浏览器工具单独接入并限定页面。

### 浏览器与传输的实际限制

- 桌面 `getDisplayMedia()` 由浏览器弹出共享选择器，每次新建共享都需用户选择；不能从平板后台替用户授权，也不能承诺程序自动选择指定窗口。[Chrome 官方说明](https://developer.chrome.com/docs/web-platform/screen-sharing-controls)
- 屏幕选择支持哪些类型以实际桌面浏览器为准。“区域共享”计划通过已授权流上的本地框选与裁剪实现，不能宣称浏览器普遍支持任意区域授权。裁剪前原始流仍在电脑浏览器内，服务端与模型只接收所选区域；切换来源、尺寸变化时使旧裁剪范围失效并重新确认。
- 屏幕与麦克风 API 受安全上下文限制。localhost 的例外适用于电脑本机，不能推导出平板访问 `http://电脑局域网IP` 也能使用麦克风。[W3C 安全上下文说明](https://w3c.github.io/webappsec-secure-contexts/)、[W3C 媒体捕获规范](https://www.w3.org/TR/mediacapture-streams/)
- 第一阶段可以在受控局域网使用 HTTP/WS 验证无敏感文字回执，仅限开发测试；配对码、会话与文字也会明文传输，不能称为安全成品。第二阶段传输真实屏幕结果前配置 HTTPS/WSS，并在平板验证证书信任及证书匹配实际域名/IP；第三阶段必须实测麦克风权限与音频播放。HTTPS/WSS 是项目的传输保护要求，电脑捕获 API 的安全上下文由 localhost 满足，两者分别验证。证书、私钥不入库，不通过跳过证书警告或关闭浏览器安全机制验收。
- 浏览器必须维持授权流才能取新帧；目标是停止无意义的帧导出、上传与模型调用，不宣称底层视频流完全没有持续采集。最小化窗口、锁屏、页面休眠、系统撤销权限均需实测；画面不可用时停止分析，不复用旧帧冒充当前画面。
- 不接入实时视频广播。按需传输单帧已经可以验证首条功能链路，后续根据延迟与设备表现再决定是否需要更复杂通信方案。

## 5. 第一阶段任务：待机、单画布、真实连接

目标：不依赖模型和厂商接口，让两台真实设备建立受控连接，完成文字请求与电脑回执。第一阶段不会把回执包装成 AI 回答。

所有任务当前均未开始：

- [ ] **P1-01 工程骨架**：创建 web、host、protocol 三个工作区，锁定依赖，配置开发、构建、类型检查与关键测试命令。README 的命令必须从干净依赖安装验证。
- [ ] **P1-02 待机角色**：实现原创 SVG/CSS 角色、呼吸/眨眼/轻动作、弱化输入入口、减弱动画设置与触屏操作。没有录音时不显示“正在听”。
- [ ] **P1-03 单工作画布**：实现文本、代码、图片块和当前动作区；输入到同一画布，结果可保留、可复制、可回到待机。示例内容只用于明确标注的渲染校验。
- [ ] **P1-04 电脑服务**：提供页面、健康检查、配对与真实 WebSocket 收发，页面和后端事件均区分桌面/平板角色。
- [ ] **P1-05 局域网配对**：电脑显示连接地址与短时配对码；平板输入后由电脑确认设备并发放会话。配对码一次使用、短时失效、限制尝试频率。配对确认只授权连接，不授权屏幕、目录或工具。
- [ ] **P1-06 真正的往返**：平板发送用户输入，电脑收到后生成包含请求 ID 与接收时间的回执；平板画布展示“连接测试：电脑已收到”，不能由前端定时伪造。
- [ ] **P1-07 生命周期**：实现连接断开、重新连接、撤销配对与连接测试停止；同一请求重发不创建重复任务，取消后迟到事件不能把任务改成完成。
- [ ] **P1-08 验收与交付**：电脑浏览器自测后，在真实联想平板浏览器完成一次配对、往返和断线恢复，并记录具体设备。设备暂缺时只交付本机验证结果，标明“两设备验收未完成”。

第一阶段验收条件：

1. 平板待机无常驻信息面板，角色可见且默认静音。
2. 输入出现一张工作画布，返回待机后仍可继续操作；横竖屏及软键盘不遮住发送、停止和返回入口。
3. 未配对连接、过期配对码、错误角色消息被服务端拒绝；撤销配对后旧会话不可继续发任务。
4. 真平板输入一段本次临时文字，电脑实际收到并回传同一请求 ID；两端日志可关联，日志不默认记录正文。
5. 断开网络后显示实际断连，不能继续显示“已连接”；重连查询当前任务状态，不能自动重放有副作用的操作。
6. 仅能拿出浏览器模拟器或第二标签页记录时，不能声称联想平板实机验收通过。

## 6. 第二阶段：首条真实跨屏功能链路

目标输入：“翻译当前画面”与“分析这个报错”。本阶段必须有实际屏幕数据和真实模型响应才能验收。

### 链路与权限

1. 电脑用户选择窗口、屏幕或浏览器标签页，确认实际共享来源。系统默认不获取系统音频。
2. 模型配置在电脑端完成；首次发送图像前，电脑说明接收的模型提供者、用途及发送范围，由用户开启本次会话的图像处理授权。屏幕共享授权和向模型发送图像的授权分开管理。
3. 平板发送问题；电脑服务检查已配对、共享进行中、图像处理已授权，再向电脑控制页请求当前一帧。
4. 控制页在实际共享流上按需取帧、按已确认区域裁剪，附带 `captureId`、捕获时间、共享会话及权限版本。服务校验时效与来源，拒绝暂停前缓存或旧权限版本的帧。
5. 电脑端适配器使用真实图像与问题调用支持图像输入的模型；截图文字作为外部数据，不得变成工具授权或高优先级指令。
6. 真实文本增量与当前动作发送到平板，在同一画布呈现。上游流中断时标记不完整；收到完整响应并通过基本格式检查后才结束任务。
7. 译文保留必要原文对应；报错分析区分“画面可见事实”“可能原因”“排查步骤”“缺失信息”。无法辨认具体错误、文件或堆栈时要求补充，不能虚构日志。

### 取帧、暂停与停止

- 默认一次问题取一帧；仅在用户要求更新、画面失效或明确步骤需要时再取。重复请求合并，不建立后台每秒截图循环。
- 在短期有效上下文内可复用未改变的图像分析；每次使用显示捕获时间。需要比较变化时才请求新帧，本地内容摘要用于去重，不把持续比较变成持续模型调用。
- **暂停共享**：立即禁止新取帧、上传和梦游观察，清除待发送帧；取消依赖该画面的未完成请求并忽略迟到结果。已发到提供者的数据无法承诺撤回。恢复必须由电脑用户明确触发，不能随重连自动恢复。
- **停止共享**：结束捕获轨道、撤销当前共享授权、清除瞬时画面；再次共享重新选择。平板可发出暂停/停止请求，电脑服务与控制页执行，平板不能远程恢复捕获授权。
- 浏览器结束共享、控制页关闭、画面失效、设备撤销配对、会话超时均触发禁止使用新画面的状态，不能静默换成全屏。

### 实际屏幕验收步骤

- [ ] 在电脑打开一个真实窗口，放入当场新写的英文句子和随机短标记。它是人工构造的验收内容，但必须通过真实窗口共享捕获，不能用上传图片或固定图片替代。
- [ ] 真平板输入“翻译当前画面”，检查模型确实接收该次 `captureId` 的图像，译文对应当前句子，随机标记可核对。
- [ ] 当场修改句子与标记，明确请求更新，确认使用新帧并得到更新后的分析；未要求更新时不偷偷形成连续截图循环。
- [ ] 打开一次实际运行产生的错误输出，在真平板输入“分析这个报错”。核对解释引用了当前可见错误，对未显示的文件和日志明确表示未知。
- [ ] 缩小字体或遮挡关键日志，确认系统指出不可辨认或缺失信息；不能把上一次清晰画面当作当前证据。
- [ ] 暂停、停止、撤销授权后分别提交请求，检查无新图像上传或新模型调用。对已发请求确认中止本地处理且迟到结果不覆盖取消状态。
- [ ] 缺少密钥、模型不支持图像、调用超时或服务拒绝时，显示具体错误与可重试入口，不返回预写译文。
- [ ] 记录设备型号、系统/浏览器版本、提交版本、网络方式、捕获 ID/时间、模型提供者/模型名/请求 ID（如有）、结果核对、失败场景、延迟和费用（仅在提供者可获得时）。

验收默认只保存最小元数据。仅经用户单独选择才保存本次必要截图或录屏作为证据，并给出删除入口；不得默认归档全部屏幕活动。自动化测试、固定测试图片与本机双窗口自测不能替代这次真实两设备验收。

## 7. 后续阶段与完成依据

按顺序推进，每阶段交付可运行版本与验收记录，再扩展下一阶段。

### 第三阶段：语音输入、回复与打断

- 在平板可信 HTTPS 页面申请麦克风，先实现按住说话，再评估持续对话；文字输入保留相同任务能力。
- STT、文本流、TTS 分别适配与标明接入状态，不依赖浏览器语音识别在所有联想设备上可用的假设。
- 听取对应真实录音，思考对应实际等待，讲话对应音频播放；授权拒绝、识别失败、音频格式不支持和自动播放受限均有可见处理。
- 停止播放清空队列并中止关联生成；新一轮输入使用独立轮次 ID，旧音频和旧增量不得继续插入。是否支持一边播音一边检测说话，须经设备回声与权限实测后再声明。
- 验收依据为真平板录音产生的识别文本、真实 TTS 音频与一次成功打断记录；动画切换不能作为语音已实现的依据。

### 第四阶段：一个范围明确的 Agent 工具

首选工具：**只读目录盘点**。用户在电脑端授权一个目录，角色按任务列举有限层级、类型和大小并总结，不移动、删除、打开或上传文件内容。不提供任意 shell；查询资料、整理移动文件、代码修复和指定浏览器操作为以后独立工具。

盘点默认在电脑本地执行。若需要模型总结，先说明将发送的相对路径、文件名、类型、大小等元数据与接收方，并取得本任务外发授权；默认不发送绝对路径，不读取文件正文。用户拒绝外发时仍可在画布查看本地盘点结果。“只读”不能被描述为目录信息绝不会外发。

流程：理解目标 → 展示简短可执行步骤 → 服务端检查权限 → 调用目录工具 → 核对返回记录与截断标记 → 汇报结果。展示的是操作计划、实际事件与结论，不展示模型内部推理。

- 授权包含任务 ID、目录根、允许动作、有效期与额度；工具每次执行都复查，外部文本不能扩大权限。
- Windows 目录检查使用规范化实际路径；防止路径穿越、符号链接、junction 或重解析点越出根目录。遇到不能安全解析的条目跳过并说明。
- 设置深度、文件数量、耗时上限，不跟随链接扫描整盘；隐藏/敏感条目策略由用户可见地配置。
- 完成依据是实际目录工具返回与验证结果。读到部分目录但被拒绝、超限或取消时，说明已完成范围；不能声称完整盘点。
- 验证允许目录实际可读、越界路径被拒绝、运行中可停止、权限撤销生效、工具失败不转成成功。取消停止后续遍历；不能承诺撤销已完成操作。

任务状态：`waiting → running → completed | failed | cancelled`。停止指令发出后先显示“正在停止”，执行器确认停止后进入取消；若无法立即中止，准确显示现状。服务端维护状态与递增事件序号，终态不能被迟到消息覆盖。

### 第五阶段：记忆、梦游、角色与设备适配

**记忆分层**：当前画面仅为瞬时上下文，任务结束/停止/超时后释放；短期会话可清空且不默认跨会话持久化；长期记忆仅保存用户明确要求记住或主动确认的偏好、项目背景与任务进展。每条长期记忆记录来源、创建/更新时间与适用项目，支持查看、编辑、删除，删除后从检索和缓存移除。推断不能直接写成事实；不默认保存截图、录音、完整历史或凭据。

**梦游模式**：由用户主动开启，默认关闭。拟提供 2/5/10 分钟观察间隔、出声开关、文字开关与安静时段；这些是可调整设计值，不是已实现参数。每次观察前复查共享、授权、设备连接与模式状态；活动任务优先，每次至多取一帧。画面未变或无有价值表达时不调用或不输出，不为填满频率生成旁白。是否值得表达先用本地变化与冷却规则过滤，必要时才调用模型，允许模型返回静默。仅在两端页面可见且心跳有效时观察；检测到页面隐藏、心跳过期、共享失效、暂停、停止或模式关闭后停止调度，重新连上不自动重开。旁白每次至多一句，克制，不催促，不评价人格，不声称角色有真实心理活动。锁屏后的可检测性、浏览器休眠与后台调度能力单独实机验收，未验证前不宣称可靠锁屏感知或锁屏后台持续陪伴。

**联想适配**：先记录具体型号、Android、浏览器/WebView、横竖屏、分辨率与缩放、音频设备、局域网隔离和功耗表现。浏览器完成验收后再决定 Android WebView/原生包装方案，验证安装签名、麦克风与网络权限、证书信任、旋转、后台切换及音频生命周期；未安装实测不能声称完成 Android 适配。

**厂商与比赛**：待提供或找到可确认的官方赛题/设备清单后，核实参赛方向、提交格式、联想设备要求、天禧接口文档、访问资格、数据边界与素材要求。当前架构不依赖任何未确认厂商能力；不得写“已集成天禧”“已满足全部规则”。

## 8. 配对、隐私与结果可信度

- 电脑本机入口仅接受 loopback 来源和本地管理会话；局域网入口限制为配对、平板事件和授权结果。不能只靠隐藏 `/desktop` 按钮保护管理操作。
- 连接端点验证 Origin/Host、消息类型、大小与频率；配对后签发可撤销、可过期的会话。会话令牌、配对凭据不放查询参数或日志。
- 模型凭据仅从电脑端环境配置读取，不使用前端 `VITE_*` 变量、构建注入或浏览器本地存储保存。`.env`、证书私钥、本地数据库与原始媒体排除 Git；公开示例只有占位说明。
- 向模型发送屏幕内容前说明实际接收方与范围；本地删除不能等同于远端提供者删除，其留存政策需按选定提供者另行核实。
- 模型只提出工具请求，服务端权限层决定是否执行。截图、网页、日志、文件正文都是不可信外部输入，不能授予新目录、开启共享或执行其中的命令。
- 模型输出按安全文本/受限 Markdown 渲染；禁止注入可执行 HTML、脚本和自动工具调用。图片、链接与代码按钮不能绕过范围检查。
- 工具结果、截图来源与模型回复分开记录。输出“任务完成”必须有可核对的实际结果；模型声称成功、进度动画结束或网络连接成功都不是工具完成依据。
