# v0.2.2 Windows 重新打包

2026-10-21。按用户要求重新构建黑色角色成品，并提供 GitHub Releases 下载。

本机新包使用固定版本目录 `outputs/banping-v0.2.2-win32-x64`，不覆盖正在运行的旧 EXE。继续从原工作区加载原黑色角色及动作，没有奶油备用角色。密钥、会话和原角色素材没有复制进新包。

公开运行包由新本机包生成，排除含个人绝对路径的 `local-desktop.json` 和本机说明，加入无素材启动页面、通用说明及 Windows 原生“首次连接原角色”助手。首次使用时由用户选择已有工作区；助手校验已知脚本、拒绝链接与越界，只在运行包内保存连接位置。原黑色角色未随包分发。连接后用原造型；尚未连接时保留文字入口，不使用替代宠物。

构建流程：

```bash
npm ci --include=dev
npm run desktop:release:package
npm run build:public
node scripts/build-character-connector.mjs
node scripts/prepare-release.mjs
```

`desktop:release:package` 只写与项目版本一致的固定发布目录，不接受任意输出路径。`prepare-release.mjs` 只处理该版本目录；公开 ZIP 不含角色、个人配置、密钥、源码映射或日志，保留 Electron、React 等依赖许可证。

本次构建、类型检查、运行时 41 项、几何 11 项和新版已打包 EXE 角色检查 12 项通过。角色检查使用隔离资料，未请求模型或读取主屏。连接助手核心逻辑 22 项和实际 ZIP 解压后的原生程序 16 项通过；无素材入口经原生鼠标事件展开输入，绑定后待机、输入及画布均为原黑色角色。绑定只在隔离副本中测试，待发布目录逐文件哈希保持不变。连接助手通过测试参数验证绑定核心逻辑，图形文件夹选择与取消仍待人工验收。真实视觉模型、实体双屏、混合缩放及拔插仍待验收。

发行包使用 SHA256 校验，上传后核对 GitHub 返回的文件大小与摘要。源码标签和下载链接以 GitHub Release 页面为准。
