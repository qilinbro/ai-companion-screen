## 分阶段完成依据

1. **桌面基础**：Windows 实际启动；待机/单画布、托盘、真实 IPC、手动记忆增删改查/导出及重启验证。不能称模型记忆或 Agent 已实现。
2. **真实理解**：真实文本/图像模型，使用本次授权窗口取帧；现场改内容后结果对应变化；缺信息明确指出。跨会话检索已确认记忆且可纠错删除。
3. **受限执行**：用户指定目录的只读工具实际返回，越界拒绝、停止有效、验证后汇报；目标跟进有真实事件与通知去重。
4. **真实语音**：实际录音、识别、合成与中断验收；文字操作保留。
5. **实际跨屏**：真实联想平板配对，平板提问触发电脑当前取帧和真实模型，平板画布显示结果；再验收梦游与目标设备适配。

前三阶段通过后才称“电脑常伴 Agent 最小可用版本”。完成跨屏、Android 安装适配、天禧接入与比赛符合性是不同结论，必须分别有证据。
