伴屏 v0.2.2 Windows 公开构建说明

新版便携运行包下载：https://github.com/qilinbro/ai-companion-screen/releases/tag/v0.2.2
完整解压后运行“首次连接原角色.exe”，选择自己已有的伴屏工作区，之后双击“伴屏.exe”。助手不下载、复制或分发原素材；没有素材也可直接用文字入口与聊天画布。详见 README-RELEASE-WINDOWS.txt。

以下是仅校验无素材页面的源码构建流程，与新版带连接助手的运行包不同。
双击“伴屏 Demo.exe”启动。无需安装 Node.js 或每次编译；请保留整个运行目录及依赖许可证。
此版本不随附原黑色角色，也不再使用奶油色备用角色；待机位置显示“原角色未随附／点击输入”的文字入口，聊天、设置与画布仍可使用。不含第三方学习角色，也不依赖原角色工作区路径。
源码构建要求 Windows 10/11 x64 和 Node.js >= 22.12：
  npm ci --include=dev
  npm run build:public
  node scripts/package-demo.mjs
仅从源码启动公开校验页面时运行 npm run desktop:public:start。
默认 build、desktop:start、desktop:package 和 build.cmd 均为本机原黑色成品入口，请勿用默认命令替代以上公开校验命令。
此旧公开校验命令只生成无素材 Demo，不含连接助手。v0.2.2 完整运行包构建步骤见 docs/09-v0.2.2-release.md。

单击文字入口展开输入；按住入口拖动；Ctrl+Alt+Space 唤出。关闭窗口停止任务并收至托盘，从托盘选择退出才完全结束程序。
在设置填写有权使用的 OpenAI-compatible Chat Completions 服务地址、模型及密钥。程序不提供模型账号或额度。
密钥在设置框录入后交主进程管理，可选择系统安全存储；不进入日志或公开包。
对话和截图默认仅保留在内存。读屏授权仅当前运行有效，更换服务或模型后重新授权。
只有模型发出合法工具请求并通过本地授权检查，主屏图像才会发送到你配置的服务。

设置内可选择画布显示器；全屏通过按钮进入，按钮或 Esc 退出。画布位置与主屏采集来源独立。
本轮已完成构建、模拟几何和受控协议检查；受控回复不代表真实模型效果。
真实视觉服务/型号、实体双屏、混合缩放和拔插仍待验收。v0.2.2 新包已进行隔离资料的 Windows 原生启动和角色入口检查；具体范围以发行说明为准。
语音、终端执行及跨设备连接尚未实现。项目自身尚未选择开源许可证，依赖记录见 docs/third-party.md。
