伴屏 v0.2.2 · Windows x64 便携运行包

请先完整解压，保留整个文件夹，不要只移动 EXE。

第一次使用
1. 双击“首次连接原角色.exe”。
2. 选择你已有的伴屏工作区。该目录内应已有 vendor/grok-study/replica 原角色文件。
3. 连接成功后程序自动打开。以后直接双击“伴屏.exe”即可。

这个运行包不附原黑色角色素材，也没有奶油色替代角色。连接助手只核对现有文件并记录本机位置，不下载或复制角色，不读取模型配置和密钥。需自行持有有权使用的原素材。
尚未连接时，主程序保留可点击的文字入口和聊天画布；连接原角色后使用原黑色造型及原动作。取消连接选择不会修改设置。
连接后会在本机解压目录生成包含本机位置的连接文件，请勿将已连接目录重新公开上传；分享请使用原始下载 ZIP。

基本操作
单击角色展开输入，按住身体拖动；Ctrl+Alt+Space 唤出。
发送需求后显示单张画布。设置中配置兼容模型服务及画布显示器。
画布支持全屏、退出按钮和 Esc。关闭窗口停止任务并收至托盘，从托盘选择退出才完全结束程序。

模型与数据
服务地址、模型和密钥需自行配置，程序不提供账号或额度。
密钥由主进程管理，可选择系统安全存储。截图和对话默认仅保留在内存。
主屏读取仅本次运行授权有效，合法模型工具请求获准后才采集并发送到所配置服务。
连接角色不会复制个人设置。选择现有工作区后，程序沿用该工作区的本机配置目录。
