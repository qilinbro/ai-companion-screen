不需要模型服务的检查：
1. npm ci --include=dev
2. npm run build
3. node apps/desktop/electron/agent-runtime.fixture.cjs
4. node scripts/test-window-layout.mjs
预期测试数：运行时 41，窗口几何 11。第 3 步依赖第 2 步生成的当前主进程文件。测试中的 fixture-model、fixture-private-key 及 1×1 PNG 均为显式测试数据，无真实账户或模型推理。
附《运行时与几何测试记录.txt》是本次材料整理时重新执行上述既有脚本的输出；没有据此增加桌面实测结论。

Windows 原生协议链路检查：
完成构建后运行 npm run test:desktop。该脚本启动真实 Electron 生产页面及隔离的本机受控兼容服务，可能短暂显示纯色测试窗口并使用系统剪贴板；不调用外部模型。它会覆盖原生链路的基础检查。公开源码缺少第三方角色，因此不要运行本机原角色专用脚本 test:local-character 或 test:local-desktop。
附《Windows原生受控测试-脱敏.json》来自此前本机专用 EXE 的既有 30 项记录，包含原角色点击修复断言。它不是本次新增测试，且不能通过普通公开角色构建直接复现全部角色专用断言。公开材料未附本机专用 EXE、原始屏幕图片或该第三方角色。

真实模型待验收步骤：
1. 启动公开源码生产入口 npm run desktop:start，在设置填写有权使用的兼容 Chat Completions 服务、真实视觉模型型号和密钥。记录所用服务、型号和日期，不公开密钥。
2. 连接检测只验证文字、流式与工具协议；确认提示中仍注明未测试视觉能力。
3. 先发送普通文字需求，应直接回答；授权本次运行主屏读取后询问当前屏幕，核对真实工具请求、主屏图像和同一模型的后续回答。
4. 更改主屏测试内容再问，确认获得新画面。拒绝/撤销授权后核对没有采集或外发图像。
5. 流式回复时停止，核对迟到文字不再显示；分别测试超时、认证错误和服务断流后正确结束。

真实硬件待验收步骤：
连接同机第二台显示器，在设置选择画布显示器并进入全屏，分别用按钮和 Esc 退出，收起后检查宠物原位置；任务进行中切屏不得重发或丢失回复。再实测混合缩放、边缘/任务栏、拔出副屏及重连，核对始终可见。不要把几何模拟或单屏全屏作为这项验收结果。
仍需人工覆盖快速拖动、托盘、全局快捷键、物理睡眠与真实网络故障。跨设备、语音和终端功能不在当前范围内。
