# 伴屏 AI Companion Screen

一只安静住在桌面角落的小伙伴。输入需求后，模型决定是否查看当前屏幕，再在单张画布中逐步回复。

本次对话的最终需求、实现、验证和待办见 [2026-10-20 对话总结与交接](docs/05-session-summary-2026-10-20.md)。当前交付为 Windows 本地交互 Demo，真实模型效果及完整常伴 Agent 能力仍按项验收。

## 打开与配置

克隆仓库后，在工程目录安装依赖并运行 `npm run desktop:dev`，Windows 也可双击 `dev.cmd`。仓库不包含第三方学习素材，缺少素材时自动使用原创 DotPet。

仅在已有学习素材的本机工作区，最外层 **`原角色演示.cmd`** 或上述开发命令会使用原黑色角色动画；该本机入口和素材不随仓库提供。

本机生成的便携版位于 `outputs/伴屏-Demo-win32-x64/伴屏 Demo.exe`，请复制整个目录；从仓库获取源码后可运行 `npm run desktop:package` 生成。便携产物不直接提交到源码仓库。原角色仅本机学习加载，不进入仓库、构建或分发；便携版使用原创 DotPet。

单击宠物或按 `Ctrl+Alt+Space` 展开输入；按住宠物身体即可拖动，松手不会展开对话。快捷键不可用时从托盘展开。通过设置图标填写 **OpenAI-compatible Chat Completions 服务地址、模型名称和密钥**。服务与模型默认留空，不读取其他应用或环境变量中的凭据。

- 服务与模型需支持流式回复、工具调用，以及图片输入，才能完成屏幕分析。普通文字对话也需要可用的兼容服务。
- 密钥由桌面主进程管理，不回显、不写入前端状态或日志；选择“保存在本机”时使用系统安全存储加密，不支持安全保存时仅本次运行有效。更换服务不会沿用旧服务密钥。
- “允许模型查看当前屏幕”仅本次运行有效。勾选后，模型需要时可把真实主屏图片发送到所填服务；重启后需重新授权，修改服务/模型也需重新勾选。

## 当前交互

默认只有宠物与折叠输入。发送需求后出现窄边框画布，原角色留在角落；等待时显示轻微三点动画，回复按实际数据流逐步出现，支持停止与复制。

角色随真实工作阶段切换原项目动作：等待时思考，查看画面时观察，流式回复时书写；回复完成短暂开心，失败时疑惑，拖动时被提起。停止立即恢复待机，松开拖动后恢复当前工作动作。

前端不按关键词选择任务或伪造分析。模型通过 `capture_screen` 工具决定是否获取一次真实主屏 PNG；授权不足时不会发送图片。工具名称和参数不铺在主界面，取得的画面可按需展开查看。

对话与图片仅保留在本次内存，不默认存盘或写入 localStorage。模型调用会把需求、有限近期文字上下文，以及本次获准的图片发送至所选服务；后续历史不自动重发旧截图。更换服务/模型会开始新会话。当前没有 OCR、语音、终端命令、文件修改、网页搜索或电脑控制，也没有本地 HTTP 工具服务。

## 开发与验证

需要 Windows 10/11 x64、Node.js >= 22.12 和图形桌面；首次安装依赖需要联网。

```bash
npm install --include=dev
npm run desktop:dev
npm run build
npm run desktop:package
```

打包替换 `outputs/伴屏-Demo-win32-x64/` 的旧产物；修改桌面主进程后需重启应用。
