伴屏 AI Companion Screen · Windows 模型对话 Demo
更新：2026-10-20

打开

从仓库获取源码后，在工程目录双击 dev.cmd，或安装依赖后运行 npm run desktop:dev。
仓库不包含学习素材，缺少素材时自动使用原创 DotPet。
仅在已有学习素材的本机工作区，可双击最外层“原角色演示.cmd”使用原黑色角色。
原角色仅供本机学习，不随仓库、构建或便携包分发。
便携版需本机运行 npm run desktop:package 生成，不随源码仓库提交。
使用时复制整个“伴屏-Demo-win32-x64”目录并打开“伴屏 Demo.exe”；
便携版使用原创 DotPet，不需要安装 Node.js。

配置模型

点击宠物或按 Ctrl+Alt+Space 展开输入，快捷键不可用时从托盘展开。
按住宠物身体即可拖动窗口；松手不会展开对话，单击仍可展开。
点击设置图标，填写兼容 OpenAI Chat Completions 的服务地址、模型和密钥。
默认不预填服务或模型，不读取环境变量及其他应用的凭据。
服务必须支持流式回复、工具调用和图片输入，才能完成屏幕分析。

密钥不回显，由桌面主进程保存与用于请求。“保存在本机”使用系统安全
存储加密；安全保存不可用时仅本次运行有效。更换服务不会沿用旧密钥。
“允许模型查看当前屏幕”只在本次运行有效：需要时，画面会发送到所填
服务。重启或修改服务/模型后需重新勾选。保存配置不会自动发送原需求，
确认后再发送即可。

使用与边界

默认只有宠物和折叠输入。发送需求后，宠物留在窄边框画布角落；
等待时显示三点动画，实际回复逐步出现，可停止、复制或收起。
原角色动作随真实阶段切换：思考、观察、书写、完成开心、失败疑惑。
拖动时被提起，松开恢复工作动作；停止立即恢复待机。完成/失败反馈约2.4秒。
模型自行决定是否调用 capture_screen，前端不按关键词分类、不伪造分析。
主界面隐藏工具名称和参数；实际取得的画面可按需展开查看。

需求、有限近期文字上下文和获准的本次屏幕图片会发送至所选服务。
对话与图片只留在本次内存，不自动存盘或写入 localStorage；历史不自动
重发旧截图。切换服务/模型开始新会话，退出后不自动恢复。
当前没有 OCR、语音、终端执行、文件修改、网页搜索、电脑控制或本地
HTTP 工具服务。浏览器预览不能直接读取桌面或调用桌面模型桥接。

验证

完整构建通过（动作联动后生产渲染 30 个模块），23 项运行时夹具通过，
静态设计检查未报项。Windows 原生 UI 已通过本地受控 SSE 服务链路：两次请求，
toolRequested、imageReceived、pngValid 均通过。这是固定响应测试夹具，
证明流式/工具/真实图片传递链路，不是真实模型的识图与分析效果验收。
新版便携包已生成，并在 Windows 空配置下确认启动、角色待机和快捷键唤起输入。
尚未用用户真实服务验收；其余边界见工程内 docs/04-dot-demo.md。
